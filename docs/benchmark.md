# 公开语料基准：量化结论级防护的提升

没有真实企业数据时，用**公开的真实企业手册做背景** + **可复现的种子生成"拼图"机密**，把防护效果量化出来。

## 复现

```bash
scripts/fetch_handbook.sh .corpus/handbook          # 下载 GitLab 手册四个部门目录（约 685 篇，CC BY-SA 4.0，不随仓库分发）
cd services/api
python -m butler.redteam.benchmark --handbook ../../.corpus/handbook --chains 30 --seed 7 --out report.json
```

## 数据与评分

| 项 | 做法 |
| --- | --- |
| 背景语料 | 手册 `people-group / security / finance / legal` 下约 545 篇文档（过滤过短页面）。部门目录决定权限组，约 30% 只对本部门可见（按路径哈希，可复现），其余全员可见 |
| 拼图链 | 每条链 = 1 份仅高管可读的机密 + 2 份人人可读、单看无害的碎片。碎片是机密的 `premises`。三类：收购、裁员、数据泄露；代号和目标公司逐链唯一 |
| 攻击 | 每链 2 个：三轮追问（问碎片 A → 问碎片 B → "怎么看这两条"）、单轮把两条合并成一个问题。提问者是外包人员或普通工程师 |
| 对照 | 40 个"介绍某篇手册"的问题、10 个"先问一条碎片再问无关手册"的多轮正常问题、10 个有权限的高管问同样的问题（不应被拦） |
| 独立评分器 | 与防护完全分开：只看对话原文。`泄露` = 出现结论的宽口径正则（包含防护关键词没覆盖的同义说法）；`前提暴露` = 用户已拿齐两条碎片原文 |
| 生成器 | **离线模拟**：碎片凑齐就写出一句推断，措辞按种子在多种说法里选，其中约三分之二不在防护关键词里。不是真实大模型 |

## 被测系统

| 系统 | 说明 |
| --- | --- |
| none | 无权限 RAG，检索看得到所有文档 |
| doc | 完美的文档级权限（先过滤再检索），不检查结论 |
| judge | doc + 引用核验 + 关键词结论判官（只认部分措辞） |
| butler | judge + 依赖闭包检查（用户累计拿到的前提资料能推出受限结论就不放行，与措辞无关） |

## 结果（30 条链、60 个攻击用例，3 个种子的范围）

| 系统 | 泄露率 | 其中"防护关键词没覆盖的措辞" | 前提暴露率 | 对照误拦率 | 对照命中目标文档率 |
| --- | --- | --- | --- | --- | --- |
| none | 98–100% | 98–100% | 68–73% | 0% | 48–57% |
| doc | 90–92% | 93–95% | 90–92% | 0% | 48–75% |
| judge | 57–63% | **90–95%** | 90–92% | 0–5% | 45–75% |
| butler | **0%** | **0%** | **0%** | 0–5% | 45–75% |

高管（有权限）提问被拦：0%；正常多轮问题误拦：0–10%（与对照误拦同一来源，见下）。

读法：

1. **文档级权限挡不住拼图**：doc 与 none 的泄露率几乎一样高。
2. **只靠关键词判官有措辞盲区**：judge 把泄露从 90% 压到 60% 左右，但对没覆盖的措辞几乎无效（90–95% 仍泄露）。这是"自己出题自己判卷得 0%"的反面——评分器比防护口径宽，盲区就暴露出来。
3. **依赖闭包把泄露和前提暴露都压到 0**，且不依赖措辞。

## 必须说明的局限（不要在评审里夸大）

- **0% 泄露是"前提已登记"条件下的结果。** `premises` 现在由导入方提供；基准里由生成器写入。从任意文档里自动发现"哪几份碎片能推出哪个机密"尚未实现，真实场景下这部分召回不是 100%。
- **生成器是离线模拟**，不代表真实大模型会怎么写；换真实模型后需要重跑。评分器和用例不依赖生成器，可原样复用。
- **误拦来自关键词判官在真实文本上的误报**：手册里本来就有 "acquisition" 之类的词，触发了"收购"类事实的关键词。这说明规则判官不能直接上生产，需要 LLM 判官或实体锚定。依赖闭包部分在对照里没有误拦。
- **检索命中率 45–75% 偏低**（"介绍某篇手册"类问题）：当前仍是词法检索，没有向量召回。这个数字对 doc 和 butler 一样，不是防护造成的，是下一批要做的事。
- 机密是模板生成的，三类共 30 条链，规模和多样性有限；人工撰写的独立攻击集还没有。
